# Changelog

Все значимые изменения в проекте MyOs документируются в этом файле.

## [1.2.0] - 2026-01-28

### Добавлено
- **Сетевой стек**: Полноценная реализация сетевого стека с поддержкой Ethernet, ARP, IPv4 и ICMP
- **Драйвер RTL8139**: Обнаружение и инициализация сетевой карты RTL8139 через PCI
  - Поддержка RX/TX буферов
  - Polling-режим приёма и передачи кадров
  - Чтение MAC-адреса карты
- **Команда `ping`**: Реализация ICMP echo request/reply с измерением RTT
  - Парсинг IPv4 адресов из строки (формат a.b.c.d)
  - Автоматическое разрешение MAC через ARP
  - Вывод времени отклика в миллисекундах
- **Команда `nicinfo`**: Отображение информации о сетевой карте (PCI, IO base, IRQ, MAC)
- **Команда `netdump`**: Просмотр входящих Ethernet кадров для отладки
- **PCI-сканер**: Автоматическое сканирование PCI-шины и вывод всех устройств при загрузке
- **Serial-консоль**: Вывод ядра и терминала в COM1 для headless-режима (QEMU `-serial stdio`)
- **Инфраструктура стабильности**: Добавлены `panic()`, `PANIC()` и `ASSERT()` макросы для отладки

### Изменено
- **ANSI цвета**: Исправлено соответствие ANSI-кодов VGA-палитре (включая яркие цвета 90-97)
- **QEMU запуск**: Обновлён `make run` для поддержки сетевой карты и serial-вывода
- **README**: Добавлена документация по сетевому стеку и новым командам

### Технические детали
- Реализован минимальный ARP-кэш для разрешения IP → MAC адресов
- Поддержка автоматического ответа на ARP-запросы
- IPv4 checksum вычисление для корректной работы протокола
- ICMP echo request/reply с поддержкой идентификаторов и последовательностей
- QEMU user networking по умолчанию использует IP 10.0.2.15 (гость) и 10.0.2.2 (шлюз)

## [1.1.0] - (предыдущая версия)

### Добавлено
- Система пользователей и аутентификации
- Первый запуск (First Boot Setup)
- Управление процессами с иерархией
- Поддержка мыши PS/2 с колесом прокрутки
- Расширенная оболочка с автодополнением и историей
- Графическая подсистема (базовая)

### Изменено
- Улучшена файловая система с персистентностью
- Расширена система потоков
